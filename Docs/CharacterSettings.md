The following settings generally give the Fears to Fathom type look of pixellated-ish low quality on the characters faces. 
This doc is just to keep track of what worked previously on the sample face so for future faces the same look can be replicated.
- Arman

## Face texture import settings (Unity)
  Apply these to every face PNG in `Assets/Textures/Faces/`:

  | Setting | Value |
  |---|---|
  | Filter Mode | Point (no filter) |
  | Generate Mipmap | Off (under Advanced) |
  | Max Size | 128 |
  | Compression | Low Quality |
  | Use Crunch Compression | On |
  | Compressor Quality | 30 |
